# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Popcorn & Chill (formerly Cinehub; logo `public/logo.png`, also `app/icon.png`) V2 is an AI "movie sommelier" persona named Noraly (she; avatar `public/noraly-logo.png.jpg` via `components/noraly-avatar.tsx`; user-facing text must say Noraly, never Gemini; her persona lives in `PERSONA` in app/actions.ts) (French UI, dark theme, blue accent) built with Next.js 16 (App Router), Tailwind CSS 4, Framer Motion and lucide-react. The user describes what they want to watch in free text; Gemini (Vercel AI SDK) proposes up to 15 films or series (5 shown, "Show more" reveals the next 5) (anime included), which are enriched with TMDB data (poster, rating, free streaming providers in France). The original V1 (static OMDb page) lives in `legacy/` and is not part of the app; its `js/key.js` holds an OMDb key that is in git history.

The product specs are in [cinehub_v2_sp_cifications_et_master_prompt.md](cinehub_v2_sp_cifications_et_master_prompt.md) (catalogue, done) and [cinehub_v3.md](cinehub_v3.md) (AI sommelier, current).

## Commands

Package manager is **pnpm** (pinned in `packageManager`).

- `pnpm dev`: dev server. `pnpm build` / `pnpm start`: production build and server.
- `pnpm lint` (ESLint; also scans `legacy/`, where one unused-var warning is expected), `pnpm exec tsc --noEmit` for types. There is no test suite.
- Route types (`PageProps<"/movie/[id]">`, `LayoutProps`) are generated by `next dev`/`next build`; run a build if `tsc` complains about them.
- Docker: no key is needed at build time; the keys are passed at run time.
  ```
  docker build -t cinehub .
  docker run -p 3000:3000 --env-file .env.local cinehub
  ```

`AGENTS.md` warns that this Next.js version has breaking changes; read the relevant guide in `node_modules/next/dist/docs/` before using Next APIs.

## Environment

`.env.local` (git-ignored) must define `TMDB_ACCESS_TOKEN` (the TMDB "API Read Access Token", sent as a Bearer header), `TMDB_BASE_URL` (`https://api.themoviedb.org/3`), `TMDB_IMAGE_BASE_URL` (`https://image.tmdb.org/t/p`), `GOOGLE_GENERATIVE_AI_API_KEY` (Gemini) and optionally `AI_MODEL` (default `gemini-3.5-flash-lite`). All TMDB and Gemini calls are server-side; no key may reach client code.

## Architecture

- [lib/tmdb.ts](lib/tmdb.ts) is the only TMDB client. `tmdbFetch` adds the Bearer header and the `language` of the request (`tmdbLocale(lang)`, English by default) and throws `TmdbError` (with `status`). Cache Components is enabled (`next.config.ts`), so the data functions (`getMovieDetails`, `getMovieVideos`) use `"use cache"` + `cacheLife`, while `searchMedia` is deliberately uncached. `getMovieDetails` appends `credits` for the cast; `getMovieVideos` falls back to en-US and keeps YouTube only.
- AI flow: `HeroSearch` (client, home page) calls the Server Action `generateRecommendations` in [app/actions.ts](app/actions.ts). It validates the prompt (5-500 chars), asks Gemini through `generateText` + `Output.object` (zod schema: type, titre, titre_original, annee, raison_du_choix; up to 15 items; type film|serie), then for each item calls `findMedia` (TMDB `movie` or `tv` search by type; searches the original title first, then the French one; ignores TMDB entries with < 10 votes, which are false positives) and `getWatchProviders(id, type)` (region FR; free and ads providers become `freeProviders`, flatrate ones become `subscriptionProviders` (Netflix, Prime Video…)). It returns `{ ok, recommendations } | { ok: false, error }`; failures are logged with `console.error` and never thrown to the client. Model choice matters for latency: `gemini-3.8-flash` took 50-100 s, `gemini-3.5-flash-lite` about 8 s, and `thinkingLevel` is set to `low` (`minimal` is rejected by some models).
- Region: users are mostly outside France, so offers are per country. [lib/region.ts](lib/region.ts) `getRegion()` (dynamic: reads cookies/headers) returns the `region` cookie, else the country of `Accept-Language` (`fr-CA` -> CA), else FR; there is no region selector any more (the `region` cookie is still honoured). `generateRecommendations` and `MediaContent` (inside Suspense) call it, so never call it from a static page. TMDB text stays in French (`fr-FR`).
- Language: English is the default. [lib/i18n.ts](lib/i18n.ts) holds the FR/EN dictionaries (`DICTS`), `DEFAULT_LANG` and the `lang` cookie name; `useT()`/`useLang()` in [lib/use-lang.ts](lib/use-lang.ts) (client, cookie read through `useSyncExternalStore`, so the static home renders in English then switches), `getLang()` in [lib/lang.ts](lib/lang.ts) (server, dynamic). `LanguageSelect` in the Navbar writes the cookie and refreshes. The language is threaded to TMDB (`language` param of the detail/search functions), to Noraly's prompt (`lang` option of `generateRecommendations`) and to `transcribeAudio`. Add every new user-facing string to both dictionaries.
- Design system: Noraly palette as CSS variables in [app/globals.css](app/globals.css) (`--bg-canvas`, `--navy-primary`, `--accent-ice`, `--text-*`), exposed to Tailwind as `bg-canvas`, `bg-surface`, `bg-elevated`, `border-line`, `bg-navy`, `text-ice`, `text-ink`, `text-ink-2`. Fonts: Instrument Serif (`font-display`, weight 400 only) and Inter. No gradients, blur, neon or sparkles. The home title adapts to the time of day and weather ([lib/ambiance.ts](lib/ambiance.ts), Open-Meteo, geolocation asked at most once).
- Providers: `getWatchProviders(id, type, region)` returns, for that region, every offer (free, ads, flatrate, rent, buy) plus the JustWatch page link; when the region has no offer it lists the other countries where the title is streamed (`otherRegions`). TMDB gives no per-platform link, so [lib/providers.ts](lib/providers.ts) maps common provider ids to their official site (logos are clickable when known) and `groupProviders` splits the offers by kind. [components/where-to-watch.tsx](components/where-to-watch.tsx) renders the rows (free / subscription / rent-buy / other countries) and is shared by `RecommendationCard` (which adds the "Regarder gratuitement" button) and the details pages. Only providers reported by TMDB are shown; piracy/unauthorized streaming sites and Telegram channels are deliberately never linked, whatever the claimed authorization.
- Voice input: the mic button in `HeroSearch` (solo mode only) records with MediaRecorder in [components/use-speech-recognition.ts](components/use-speech-recognition.ts), converts to WAV 16 kHz mono (45 s max) and sends it to the Server Action `transcribeAudio` ([app/transcribe.ts](app/transcribe.ts)), which transcribes it with Gemini (same key). The Web Speech API was dropped because it fails with a `network` error on Chromium builds without Google's speech service. Needs HTTPS or localhost; `experimental.serverActions.bodySizeLimit` is 3mb in `next.config.ts` (Vercel caps requests at 4.5 MB).
- V2.1 features (all user data in `localStorage`, no account): [lib/user-data.ts](lib/user-data.ts) holds SSR-safe hooks built on `useSyncExternalStore` (`useWatchlist` -> `cinehub_watchlist`, `useSeenItems` -> `cinehub_seen_items`, `useHistory` -> `cinehub_history`, 5 entries). `SearchRequest` (solo or duo), the mood modifiers (`MODIFIERS`) and `parseItems` live in [lib/search.ts](lib/search.ts). `generateRecommendations(request, {exclude, modifiers})` and `replaceRecommendation` (one replacement, "Déjà vu" button) are in `app/actions.ts`; duo mode changes the system prompt and the reason explains why both people will like it. "Choisis pour moi" (roulette + `ChoiceModal`, trailer loaded lazily via `getTrailerKey`), share button, and the watchlist drawer (`WatchlistButton` in the Navbar) are client-side. `/selection?items=movie:550,tv:1399&q=...` ([app/selection/page.tsx](app/selection/page.tsx)) rebuilds a shared selection from TMDB (`getMediaSummary`) without calling Gemini and sets Open Graph metadata. Toasts: `useToast()` from [components/toast.tsx](components/toast.tsx).
- Pages: `app/page.tsx` is just `HeroSearch` (static). `app/movie/[id]/page.tsx` and `app/tv/[id]/page.tsx` are thin wrappers around [components/media-details.tsx](components/media-details.tsx) (`MediaContent`, movie or series details, trailer, where to watch, cast); it reads `params` inside a `<Suspense>` child (required by Cache Components) and calls `notFound()` on invalid ids or TMDB 404; because of streaming, that 404 page is served with HTTP 200. `getTvDetails` maps a series to the `MovieDetails` shape. The Ctrl/Cmd+K search (`/api/search`, TMDB `search/multi`) finds movies and series.
- Search: `SearchLauncher` (in the fixed `Navbar`, owns the Ctrl/Cmd+K shortcut) opens `CommandPalette`, which debounces 300 ms, aborts stale requests and calls `app/api/search/route.ts`; that route returns trimmed results (id, title, year, w92 poster).
- Trailer: `TrailerButton` opens a modal with a `youtube-nocookie.com` iframe.
- Server Components by default; only components that need state/animation are `"use client"` (`HeroSearch`, `LanguageSelect`, `FadeIn`, `SearchLauncher`, `CommandPalette`, `TrailerButton`). Images go through `next/image`, allowed by `images.remotePatterns` for `image.tmdb.org/t/p/**`.

## Deployment

`next.config.ts` sets `output: "standalone"`. Server Actions, the API route and `"use cache"` need a Node server, so static export and Nginx are not possible: the multi-stage [Dockerfile](Dockerfile) runs `node server.js` on port 3000. The home page is static and the build makes no external call, so the build needs no secret; `TMDB_ACCESS_TOKEN`, `GOOGLE_GENERATIVE_AI_API_KEY` (and optionally `AI_MODEL`) must be passed as environment variables at run time. `.dockerignore` excludes `.env*` and `legacy/`.
